The situation

Acme’s support queue never slept.

Finance and CX lived in Slack with the same three families of bugs: checkout discounts, invoice totals, refunds. A coding agent could sometimes fix one — if someone sat beside it, peeked at the failing test, and rewrote the prompt when it guessed.

The trap

Scaling agents without scaling the loop.

Three agents in parallel made things worse: half the “fixes” broke other tests, and nobody remembered which system prompt worked last Tuesday. Maya wrote it on the whiteboard:

We’re not failing because the model is dumb. We’re failing because we are still the loop.

What they built

Run. Verify. Rewrite the harness. Retry.

  1. Tickets Symptom-only briefs against acme_billing
  2. Harness Deep Agents edits code; shell optional for pytest
  3. Verify Must read the failing test, run pytest, edit the right module
  4. Improve Failures rewrite system_prompt + enable_shell
